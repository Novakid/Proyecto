Aparicio Gestión

Aplicación para administrar productos, usuarios, cotizaciones y facturas desde una interfaz web o una aplicación de escritorio.

Herramientas principales

- Vue 3 y Vite para la interfaz.
- NestJS para la API.
- MySQL y TypeORM para la base de datos.
- Electron para la aplicación de Windows.
- JWT para el inicio de sesión y los permisos.

Carpetas

- `Frontend`: interfaz de usuario.
- `Backend`: API, autenticación y acceso a MySQL.
- `Desktop`: aplicación Electron e instalador de Windows.

Preparación

Se necesita Node.js, npm y una base de datos MySQL.

Iniciar en desarrollo

Para iniciar Backend, Frontend y Electron juntos:

```powershell
npm run dev
```
